# Лабораторная 1

## Цель работы:
Получение практических навыков обработки данных в Python с использованием библиотек Numpy и Matplotlib.

## Содержание работы:
Необходимо выполнить лабораторные задания и оформить отчёт. Отчёт должен содержать краткое описание выполнения заданий, листинги программ, скриншоты результатов.

### ТЗ №1 (Порядок выполнения):

1. Сформировать одномерный массив a (размерность 10) с использованием
функции linspace;

2. Сформировать два двумерных массива b и c размера (4,4). Массив b ввести с клавиатуры. Массив c заполнить случайными числами.
3. Вывести на экран каждый массив и его атрибуты (shape, size, ndim, dtype)
4. Провести сортировку элементов массива a по возрастанию
5. Сформировать из исходного массива a двумерный массив размера (2,5); 
6. Перемножить массивы b и c
7. Преобразовать массив c в одномерный
8. Cформировать массив размера (2,3) из последних 6 элементов массива b
9. Cформировать и вывести на экран новый массив d, соединив массивы b и c по вертикали;
10. Удалить 2 и 3 столбец массива d
